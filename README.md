# \# 🏢 Office Tycoon

# 

# \*\*Office Tycoon\*\*, şirketini sıfırdan kurup büyüterek en büyük teknoloji imparatorluğu haline getirmeye çalıştığın klasik bir \*\*idle / clicker\*\* oyunudur. 

# 

# \---

# 

# \## 🚀 Özellikler (Features)

# \* \*\*Otomatik Gelir:\*\* Ofis çalışanları işe al ve sen oyunda yokken bile para kazanmaya devam et.

# \* \*\*Karakter Gelişimi:\*\* Karakterinin seviyesini artırarak daha fazla para kazanmanı sağlayan özel güçlerin kilidini aç.

# \* \*\*Geliştirmeler (Upgrades):\*\* Kahve makineleri, ofis dekorasyonları ve yazıcılar gibi eşyalar satın alarak kazanç bonuslarını artır.

# \* \*\*Şirket Büyütme:\*\* Küçük bir garaj ofisinden başlayıp devasa gökdelenlere taşın.

# \* \*\*Yatırımlar:\*\* Kazandığın paralarla yeni ofisler satın al ve ekibine daha fazla çalışan dahil et.

# 

# \## 🛠️ Kullanılan Teknolojiler (Tech Stack)

# \* \*\*Oyun Motoru:\*\* Godot Engine

# \* \*\*Programlama Dili:\*\* GDScript \*(Eğer C# kullanıyorsan burayı C# olarak değiştirebilirsin)\*

# \* \*\*Sürüm Kontrolü:\*\* Git \& GitHub
